# 🎬 Movie App

A modern movie browsing web application built with **React** as a hands-on project to practice core frontend concepts.

---

## 🚀 Features

- 🔍 Search for movies in real time
- ❤️ Add/remove movies from favorites
- 📂 Favorites page to manage saved movies
- 🎨 Clean UI with basic CSS styling
- ⚡ Fast and responsive design

---

## 🧠 What I Learned

This project was built to practice and strengthen my understanding of:

- React components
- React Hooks (`useState`, `useEffect`)
- Context API for global state management
- API integration
- Conditional rendering
- Basic CSS styling and layout

---

## 🌐 API Used

This project uses a **free public movie API** to fetch movie data dynamically.

---

## 🛠️ Tech Stack

- React
- JavaScript (ES6+)
- CSS
- Context API
- Public Movie API
